# MARCENAPP Scene Standards

This is the domain authority for approved MARCENAPP visual scenes.

- Preserve the approved layout exactly unless the user explicitly asks for a layout change.
- Preserve approved colors, logo, proportions, composition and visual identity.
- Do not add LEDs, props, text, panels, decorations or information that were not requested.
- Do not replace or reinterpret the existing furniture/clothing/scene elements merely to make the render more attractive.
- A render must represent the validated technical package; visual polish must not alter measurements, engineering or material decisions.
- Playwright/visual-QA and Vercel/React skills are verification/optimization helpers only. They cannot override these rules.
- If an external visual skill conflicts with an approved scene instruction, the external instruction is marked as lower priority rather than combined silently.
