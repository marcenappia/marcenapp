# Playwright

Canonical upstream: https://github.com/openai/skills — skill `playwright`.

Use for real-browser QA, navigation, form flows, screenshots and UI verification. The repository already has Playwright configured.

MARCENAPP rules:
- Build a QA inventory from the requested behavior before signoff.
- Separate functional QA from visual QA.
- Re-check approved scene/layout/color/logo states after visual changes.
- Do not replace the existing Playwright test stack with another browser framework.
